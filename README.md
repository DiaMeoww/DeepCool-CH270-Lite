# 九州风神 CH270 机箱数显精简独立驱动 (DeepCool CH270 Lite)

超轻量、完全自包含、开箱即用的**九州风神 CH270 机箱数显控制系统**。彻底告别官方体积庞大（数百 MB）、常驻耗费资源的 Electron 臃肿套件！

---

## ✨ 核心特性

- ⚡ **原生轻量**：基于原生 C# WinForms 与底层 Win32 API 打造，总大小仅几 MB，极低 CPU 与内存占用。
- 📦 **开箱即用**：无需事先安装或卸载九州风神官方软件，内置全套底层传感器桥接驱动，解压双击即点亮。
- 🖥️ **全模式显示**：
  - **CPU 模式**：实时轮播 CPU 温度、功耗、利用率、实时睿频与风扇转速。
  - **GPU 模式**：实时点亮机箱 GPU 指标，展示显卡温度、功耗、利用率与频率。
  - **自动轮播 (CYCLE)**：全自动交替展示 CPU 睿频、CPU 风扇、GPU 状态。
- 🌡️ **温控单位实时切换**：支持摄氏度（℃）与华氏度（℉）即时无感热切换。
- 🌀 **自由选择风扇探针**：内置支持主板各种风扇接口选择（如 `CPUFANIN0`、`SYSFANIN`、`AUXFANIN3` 等），实时读取真实转速。
- 📁 **自由重命名与路径自适应**：支持将程序文件夹随意改名（如重命名、移盘），打开自动无感更新路径。
- 🛑 **完全退出秒级响应**：特制 ACL 免提权停止与即时退出机制，退出即完全释放全部句柄与日志，绝不锁死文件夹，绝不自拉活。

## 🛠️ 项目结构

```text
├── CH270.cs             # 控制中心配置面板源码 (WinForms)

```

## 🔨 编译构建方案

本项目设计为**零开发环境依赖**。任意一台 Windows 10/11 电脑均内置了 .NET Framework 编译器，**无需安装 Visual Studio 或 .NET SDK 即可完成编译**！

### 方法一：一键编译（推荐）

直接双击运行目录下的 **`build.bat`** 即可自动完成两套组件的编译与优化输出。

### 方法二：手动命令行编译

在项目根目录下打开 PowerShell 或 CMD 执行：

```cmd
# 1. 编译前端控制面板
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /out:CH270.exe CH270.cs

# 2. 编译后台推送守护进程
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /out:CH270.Service.exe CH270.Service.cs
```

## 🚀 使用说明

1. 编译或下载发布包后，双击运行 **`CH270.exe`**。
2. 首次运行会弹出轻量提示框，点击【确定】即可一键注册并启动底层传感器系统服务（仅首次需一次 UAC 授权）。
3. 之后日常启动、切换模式、调整温控单位或风扇接口均实时生效，完全无需再次弹出 UAC 提权。
4. 如需完全停止服务或移动文件夹，在控制面板中点击右上角【完全退出】即可瞬间释放所有后台并关闭。
